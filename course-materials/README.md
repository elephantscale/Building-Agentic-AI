# Course Materials — Building Agentic AI

Reusable templates, rubrics, and checklists referenced by the slides and labs. Copy them into
your own project when you build an agent for real.

| File | Use it when you... |
|------|--------------------|
| `agent-design-canvas.md` | Scope any new agent: goal, tools, memory, stop conditions, gates |
| `tool-spec-template.md` | Define a tool the agent can call (name, schema, safety class) |
| `agent-evaluation-rubric.md` | Score an agent run for correctness, efficiency, and safety |
| `agent-safety-checklist.md` | Review an agent before it touches real systems |
| `audit-log-schema.md` | Log every plan, tool call, and result for governance |
| `capstone-rubric.md` | Grade / self-assess the final capstone project |

All templates are framework-neutral — they apply whether the agent runs on OpenAI, LangGraph,
Bedrock, DSPy, Claude, or a low-code platform.
